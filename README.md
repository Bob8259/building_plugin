# 部落冲突建筑检测插件

`部落冲突建筑检测插件` 是一个运行在 Android 设备上的辅助推理插件 / 服务。应用启动后会在本机开启本地接口，对外提供目标检测与文字识别（PP-OCRv6 small）能力，适合作为独立识别工具或通用视觉能力模块使用。

## 项目定位

`部落冲突建筑检测插件` 并不是只能绑定某一个宿主应用的专用插件，而是一个可复用、可独立部署的本地推理服务：

- 可以单独运行，安装后直接启动即可使用。
- 可以配合其他任意 APP 使用，只要对方能够访问本机接口，就可以把它当成独立的识别服务调用。
- 也可以接入自动化脚本、辅助工具或其他本地工作流，作为通用视觉识别组件使用。

## 适用场景

- 独立部署在设备上，作为常驻辅助检测服务使用。
- 给其他 Android APP 提供本地目标检测能力。
- 配合自动化项目，对截图、画面内容或局部图像进行识别。
- 用于需要本地推理、低延迟调用、避免云端依赖的场景。

## 工作方式

应用启动后会拉起前台服务，并在本机开放 HTTP 接口。调用方无需自行嵌入模型推理逻辑，只需要按约定请求接口，即可完成以下操作：

- 服务状态检查
- 模型加载
- 图像检测
- 检测结果获取
- 文字识别（PP-OCRv6 small，单接口自包含，传入图片即返回文字与位置）

默认接口地址：

```text
http://localhost:13462
```

这意味着它既可以作为一个独立应用存在，也可以作任意 APP 的插件存在。

## 主要特点

- 本地运行，无需依赖远程服务器。
- 支持作为独立插件单独启动。
- 支持被其他任意 APP、自动化程序或工具调用。
- 通过统一接口暴露辅助检测能力，便于快速集成。
- 适合需要稳定、低延迟、本地化视觉识别的使用方式。

## 一句话说明

如果把它当成一个普通 APP，它可以单独运行。

如果把它当成一个能力插件，它也可以配合其他任意 APP 一起工作。

本质上，`部落冲突建筑检测插件` 是一个可独立部署、也可灵活集成的 Android 本地辅助推理服务。
